# 📚 AnalyzeAI – Study Scheduler & Quiz Generator

An AI-powered web app that generates personalized study schedules and quizzes from your syllabus.

## Features
- 📎 Upload syllabus as PDF or TXT file
- 📅 Generates day-wise study schedule based on topics, days, and hours
- 🧠 AI-powered quiz generation using Groq + LLaMA 3
- ✅ Real-time score tracking

## Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **AI:** Groq API (LLaMA 3.3)
- **Libraries:** PyPDF2, python-dotenv

## Setup & Run

1. Clone the repository

git clone https://github.com/heavenrisers/AnalyzeAI.git

2. Create virtual environment

3. Install dependencies
pip install flask pypdf2 groq python-dotenv

4. Create `.env` file and add your Groq API key

5. Run the app
